Costumes

Costumes the game has that nobody has named. Until a costume has a name it cannot be offered in the picker and nobody can record it, so this list is the backlog. Naming one takes effect straight away, no deploy needed, and is mirrored back into the repo automatically. Look at the artwork before you name it. The game's own names are misleading (the code called "May 2019" is a straw hat, not the Detective Pikachu hat), which is how four costumes ended up pointing at the wrong picture. A name cannot be changed once trainers start recording it, so it is only removable while nobody has used it yet.

Named here

Costumes named in this panel. Removing one puts it back in the backlog above, and is the only way to correct a name. It stops being possible the moment a trainer records the costume, because removing the label then would blank the artwork on entries people have saved, and it also stops once the name has been merged into the repo and deployed.

Shiny Dex

Which species are in Pokemon GO, and which of them have a shiny released. The full National Dex ships with the app; this page only records where we disagree with it, so when Niantic releases a shiny you tick a box here instead of waiting for a deploy. Unreleased species are hidden on My Collection unless a trainer asks to see what is coming.

When a shiny is announced ahead of time, put the date in the release field. Trainers see it on the greyed card straight away, and the shiny turns itself on when the day arrives, so nobody has to remember. If Niantic delays it, untick the shiny box: an explicit tick always beats the date.

Regional and alternate forms

Forms that get their own card on the checklist: regional variants, alternate battle formes, the Unown letters and the Vivillon patterns. Only shiny availability and its release date are editable here, because the game either has a form or it does not. Scatterbug and Spewpa are absent on purpose: they carry Vivillon's patterns rather than owning them, so they follow whatever Vivillon says.
